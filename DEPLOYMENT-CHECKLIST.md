# Deployment checklist

- [ ] Verify current Monad Testnet settings from official docs.
- [ ] Compile `contracts/MonadImpact.sol` in Remix.
- [ ] Deploy from MetaMask on Monad Testnet.
- [ ] Paste contract address in `frontend/config.js`.
- [ ] Serve frontend over HTTP and test wallet connection.
- [ ] Test successful campaign, unsuccessful campaign, withdrawal and refund.
- [ ] Save explorer links and screenshots.
- [ ] Publish to GitHub and update README with deployment details.
- [ ] Do not deploy with real funds: this MVP is unaudited.
